第一步 · 对比规则说明

一、对象（Object）对比

  1. 先对比两侧对象的 Key 数量，数量不同会高亮提示。
  2. Key 数量相同时，进一步对比 Key 是否完全一致，不一致会提示「key不一致」。
  3. 对相同的 Key，再逐一对比其 Value 差异。
  4. 仅左侧（A）存在的 Key 标记为 「仅A有」；仅右侧（B）存在的标记为 「仅B有」。

二、数组（Array）对比

  1. 首先对比两侧数组的 元素个数（长度），长度不同会高亮提示。
  2. 元素为简单类型（数字、字符串、布尔等）时，按 数组下标顺序逐个对比。
  3. 元素为对象时，按上述「对象对比规则」递归对比，并可在第三步选择对比主键。
  4. 多出/缺失的元素分别标记为「仅B有」/「仅A有」。

三、可选开关

  • 忽略大小写：字符串 Value 比较时不区分大小写，如 "Alice" 与 "alice" 视为相同。
  • 忽略时间/日期类型的 Value：若 Value 是日期或时间类型，则跳过比较，直接视为相同（无论格式是否不同）。
  • 隐藏相同的 Key/Value：仅展示存在差异的节点，相同项不显示（默认开启）。
  • 折叠所有节点：默认折叠全部可展开节点，可单独点击箭头展开（默认开启）。

四、差异展示规则

  1. 数组元素按 下标顺序（或所选主键顺序）展示差异。
  2. 对象的 Key 先按 字母升序排序后再展示。
  3. 值不同时，展示形式为：左value <------> 右value。
  4. 仅左侧（A）有的 Key，提示标签写在 Key 的左侧；仅右侧（B）有的 Key，提示标签写在 Key 的右侧。
