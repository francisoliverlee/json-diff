# JSON 可视化对比工具

一个纯前端、零后端依赖的 **JSON 差异对比与字段回填** 工具。支持对象/数组的逐层差异可视化、对象数组按主键对齐、差异明细导出 Excel，以及把旧 JSON 的字段值按主键回填到新 JSON。所有数据均在浏览器本地处理，不上传任何服务器。

## 二、功能说明（五步向导）

工具采用五步式向导，顶部步骤导航条可随时点击跳转。

### 第 1 步 · 对比规则
说明本工具的对比逻辑，作为使用前的规则参考：

- **对象（Object）对比**：先比 Key 数量 → 再比 Key 是否一致 → 再逐一比较相同 Key 的 Value。仅 A 侧有的标记「仅A有」，仅 B 侧有的标记「仅B有」。
- **数组（Array）对比**：先比元素个数（长度）；简单类型按下标顺序对比；对象数组按对象规则递归对比（可在第 3 步选主键）。
- **差异展示规则**：对象 Key 按字母升序展示；值不同时以 `左value <------> 右value` 形式呈现。

### 第 2 步 · 对比文件
输入待对比的两份 JSON：

- 左侧为 **【旧】JSON (A)**，右侧为 **【新】JSON (B)**。
- 支持**手动粘贴**或**选择本地 `.json` 文件**导入，导入后展示文件名。
- 实时校验 JSON 合法性，并提示状态。

### 第 3 步 · 对比主键
当 JSON 中包含**对象数组**时，为每个数组选择**对比主键**：

- 相同主键的对象将**整体对齐对比**，而非按数组下标。
- **每个对象数组都必须手动选择一个主键**：点击任意可作主键的字段即可选定。
- **不提供、也不允许「按下标对比」**；若存在未选主键的对象数组，将无法进入下一步（会提示并定位到未选的数组）。
- 多个对象数组时，提供「上一个 / 下一个数组」快速切换导航。
- 选择某数组主键后会**自动跳转到下一个待选数组**，提升效率。

### 第 4 步 · 对比结果
差异结果可视化展示：

- 以**树形结构**展示逐层差异，并对 Key 数量 / 数组长度不一致进行高亮提示。
- 顶部按 Key 维度统计 **仅A有 / 仅B有 / 值不同 / 相同** 四类数量，点击可打开右侧抽屉查看该类全部差异明细（分页）。
- **对比选项**（实时生效，调整后自动重新对比）：
  - 忽略大小写
  - 忽略时间/日期类型的 Value
  - 隐藏相同的 Key/Value（默认开启）
  - 折叠所有节点（默认开启）
- **去掉前缀** 开关：统计时仅按最终 Key 名聚合，或保留完整前缀路径。
- **全屏查看**：差异结果可铺满视口查看（ESC 退出）。
- **下载对比明细**：导出包含 4 个 Sheet 的 Excel（统计信息 + 仅A有 + 仅B有 + 值不同，含完整前缀路径）。

### 第 5 步 · 对比回填（字段回填）
把**左侧（旧）JSON** 中指定字段的值，按**主键**回填到**右侧（新）JSON** 的同一对象 —— 右侧该字段不存在则新增，存在则用旧值覆盖：

- 自动列出左侧全部字段路径（已排除各对象数组的主键字段），支持按路径搜索过滤。
- **备选字段 / 已选字段** 双列表：点击备选项整行加入；点击已选项前的**删除图标**移回备选。
- 每个字段展示「**匹配 N**」徽章（该字段回填到右侧实际命中的处数）；点击徽章弹出该字段全部匹配值的**值统计列表**（分页，如 `value01 10个`）。
- 点击「**执行替换**」后，结果分别与旧/新文件对比，展示在两个 Tab 中：
  - **与旧文件对比**：回填结果 B' 相对旧文件 A 的差异；
  - **与新文件对比**：回填结果 B' 相对新文件 B 的差异；
  - **结果 JSON**：完整回填结果文本，可复制或下载。
  - 两个对比 Tab 的对比口径与第 3、4 步完全一致。
- **已选字段本地缓存**：按**左侧文件名**缓存已选字段，刷新页面后若左侧文件名相同且其 JSON 仍包含这些字段，则自动恢复选中，避免重复勾选工作（失效字段自动剔除）。

## 三、本地运行

本项目为纯静态页面，无需构建，直接用任意静态服务器托管即可：

```bash
# 任选其一
npx serve .
# 或
python3 -m http.server 8000
```

启动后在浏览器访问对应地址，打开 `index.html` 即可使用。

> 说明：因使用了 ESModule（`<script type="module">`），请通过 HTTP 服务访问，而非直接以 `file://` 方式打开。
